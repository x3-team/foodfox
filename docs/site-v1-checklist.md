## Анимации, которые совпадают с заметками не полностью

- Главная: секция «до 20%» — 180vh, слова blur(12px)/opacity 0.18 → 0/1 по прогрессу скролла. Колода sticky top 96/108/120, уход scale 0.94, blur 3px, opacity 0.55. `prefers-reduced-motion` снимает пин (`ok`).
- Отчёт: перелистывание 520мс и стопка U/mL с выездом по hover 400мс (`ok`).
- Лаборатории: Leaflet + OpenStreetMap, метки синхронны со списком. Яндекс JS API без ключа сейчас не отдаёт тайлы, поэтому выбран разрешённый запасной вариант (`ok`).
- Сертификаты: горизонтальная карусель из 4 PDF и просмотрщик (`ok`).
- Политика: 10 разделов. В макете часть абзацев — повтор одной заготовки «текст от юриста»; в вёрстке оставлены уникальные формулировки кадра и эта заготовка (`ok`).
- Портреты авторов: исходные изображения карточек, прямоугольный кадр 16px, не круг (`ok`).
- Блог: тайминги hover, вход, поиск и пагинация совпадают с заметками A1–A7 (`ok`).
