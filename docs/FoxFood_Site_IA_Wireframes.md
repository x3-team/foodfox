# FOX Food Xplorer — проектирование сайта (v1)

Текстовая версия проектирования, собранного в Figma на странице **«Проектирование v1 (wireframes)»**
файла [foxfood](https://www.figma.com/design/BgW10eEDt4u0udy0qlKuy0/foxfood).

Документ нужен разработке и контент-команде: в нём зафиксированы структура, URL, состояния,
логика блоков и требования к контенту. Визуальные решения — в утверждённой дизайн-концепции
(страница «Концепт 4», подложка «Анимации и Стили»).

## Сетка и типографика (из концепции)

- Ширина макета 1440, контент 1344, боковые поля 48.
- 12 колонок, gutter 24. Карточки кратны 3 / 4 / 6 (437 / 324 / 216).
- Радиусы 8 / 16 / 24 / 32. Отступы: 4 → 8 → 12 → 16 → 24 → 32 → 48 → 64.
- Manrope Light для заголовков, Regular для текста. Display 64/68, H1 56/60, H2 40/44, H3 32/36, H4 24/28, Body M 20/24, Body S 16/20, Caption 14/18.
- Чередование фонов: тёмный hero → белый → бежевый → тёмный → белый.
- Брейкпоинты: 1440 / 1280 / 1024 / 768 / 390. Поля 48 → 32 → 24 → 20.

## Карта сайта

```
/                        Главная — пациентам
/specialists             Специалистам (B2B-контур, отдельная навигация и CTA)

/course/lessons          Кабинет курса (закрытая часть, вход по magic-link)
/labs                    Где сдать тест (список сетей + карта отделений)
/labs/{city}             Гео-версия для SEO
/blog                    Лента: категории, теги, поиск, пагинация
/blog/{slug}             Статья
/blog/authors            Авторы
/blog/authors/{slug}     Профиль автора
/faq                     Вопросы и ответы (разделы + поиск)
/certificates            Сертификаты и документы
/reviews                 Отзывы (текст + видео, форма с модерацией)
/contacts                Контакты (роутинг обращений по типу)
```

Оверлеи, доступные с любой страницы: «Записаться на тест» (2 шага), «Пример результата»,
«Симптом-чекер», «Связаться», мобильное меню, cookie-баннер.

## Отчёт FOX: как читать (/report)

Одна страница на две аудитории. Sticky-оглавление слева (IntersectionObserver по H2),
контент 1016px. Блоки: три зоны реактивности → анатомия отчёта (просмотрщик с маркерами 1–5)
→ значения U/mL → anti-CCD → что делать после результата (6 карточек) → границы метода → CTA.
Зоны описаны цветом **и** названием, и уровнем — требование доступности.

## Курс

Лендинг: hero → для кого (9 специальностей) → программа (аккордеон, 6 уроков, первый раскрыт)
→ лекторы (чип с номерами уроков) → что входит (7 блоков) → FAQ (включая вопрос про баллы НМО) → CTA.
Регистрация — модалка в 4 состояниях: заполнена / ошибка+disabled / «проверьте почту» / доступ открыт.
Кабинет (/course/lessons): список уроков (done / current / next, без блокировки порядка),
плеер с субтитрами и продолжением с последнего места, конспекты PDF, сертификат — locked до 6/6.

## Блог

- Лента: закреплённый материал (не дублируется в сетке) + сетка 437×3 + пагинация страницами (?page=2, rel prev/next).
- Категории по задачам читателя: Симптомы / Питание / Как читать отчёт / Наука и метод / Истории людей / Специалистам.
- Статья: текст 760px (75–85 знаков), sticky-оглавление, sticky-CTA справа, один CTA-блок после ~60% текста, автор с регалиями в шапке и внизу, дисклеймер, Article + BreadcrumbList schema.
- Авторы и профиль автора — та же сущность «Автор / Эксперт», что и в курсе и на B2B-странице.

## Где сдать тест

Город по IP с возможностью сменить (влияет на сетку сетей, список пунктов и модалку записи).
Сеть, недоступная в городе, показывается с opacity 0.55 и действием «Смотреть города».
Список и карта связаны в две стороны; на мобильном — переключатель «Список / Карта».
Цена не публикуется никогда. Модалка записи: город → сеть → внешний сайт с UTM;
отдельное пустое состояние для городов без партнёров с захватом контакта.

## Глобальные состояния

- Header: 4 состояния. Мобильное меню: focus trap, Esc, блокировка скролла фона.
- Модалки: 568px, радиус 20, затемнение 50%, вход opacity+scale 0.98→1 за 200мс, на мобильном — bottom sheet.
- Кнопки: default / hover (+16% фон, 150мс) / focus-visible (ринг 3px) / active (scale 0.98) / disabled.
- Поля: default / focus / error (текст под полем, не только цвет) / success / disabled.
- Формы: валидация по blur, согласие 152-ФЗ обязательным чекбоксом, кнопка неактивна до согласия, состояния отправки и ошибки сети.
- Пустые и загрузочные состояния: скелетоны того же размера (без layout shift), «ничего не нашлось» + сброс фильтров.
- Доступность: контраст 4.5:1 для текста, видимый focus-visible, aria у аккордеонов и карусели, prefers-reduced-motion отключает все scroll-эффекты концепции.

## Требования к контенту и compliance

- Дисклеймер на всех страницах: FOX — лабораторный тест для поддержки персонализированных диетических вмешательств; не тест на аллергию (IgE), не устанавливает диагноз, не заменяет консультацию специалиста.
- Формулировки уровней: низкий / средний / повышенный IgG. Нельзя «продукт вреден», «запрещено навсегда» — красная зона временная.
- Цена — только «устанавливается лабораторией».
- Отзывы — с модерацией, без диагнозов и обещаний излечения.
- Сайт не хранит медицинские данные и результаты анализов; симптом-чекер работает локально.
