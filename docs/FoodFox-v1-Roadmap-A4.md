# FoodFox v1.0 — план первой полноценной версии

**Модель:** приложение бесплатно для клиента, входит в сервис после теста FOX Food Xplorer.  
**Цель v1.0:** клиент получил результат → понял зоны → прошёл программу сопровождения → дошёл до повторного теста.

---

## Что уже есть (база)

Web + Android · загрузка PDF · 286 продуктов и зоны 🟢🟡🔴 · 8-недельный план · рецепты-статьи · чат-бот по зонам и плану · кабинет · деплой на VPS.

---

## Состав v1.0 (что должно быть в «полной» версии)

| Блок | Содержание |
|------|------------|
| **Вход** | Код/QR из отчёта или авто-аккаунт по заказу; онбординг «День 0» |
| **Результаты** | Все 286 позиций, поиск, «спросить бота» по продукту |
| **План** | 4 фазы протокола FOX: элиминация → реинтродукция → жёлтая зона → ретест |
| **Питание** | Меню на день/неделю, 30+ рецептов, список покупок из зелёной зоны |
| **Сопровождение** | Push-напоминания, прогресс программы, мини-дневник (соблюдение / симптомы) |
| **Обучение** | Статьи из Knowledge Base FOX (FAQ, мифы, как читать отчёт) |
| **Чат** | Бот по протоколу FoodFox + эскалация к специалисту |
| **Команда FoodFox** | Внутренняя панель: клиенты, статус программы, «кто пропал» |
| **Compliance** | Дисклеймеры IgG, согласие на обработку данных, аудит |

## Roadmap по этапам

### Этап 1 — «После теста без трения»
Привязка отчёта (код/QR или интеграция с заказом) · онбординг · стабильный релиз APK (Play internal) · инструкция в комплекте с результатами · надёжный парсинг PDF.

### Этап 2 — «План, которому доверяют»
Полный Plan Engine (4 фазы, ротация 🟡, правила молочного профиля Bos d 4/5/8) · календарь ротации · экран фазы и «что можно сегодня» · подтверждение/коррекция плана командой FoodFox.

### Этап 3 — «Каждый день понятно, что делать»
Меню на день · список покупок · расширенный каталог рецептов · push по плану · прогресс-бар программы · дневник в 1 тап.

### Этап 4 — «Дойти до ретеста»
Реинтродукция 🔴 (продукт → наблюдение 48–72 ч) · сравнение двух отчётов · блок «Повторный FOX» · обучающие модули из KB.

### Этап 5 — «Масштаб сервиса»
Хранение PDF в облаке (S3/R2) · API лаборатории вместо ручной загрузки · аналитика для команды · iOS · публикация в Store для массовой выдачи клиентам.

---

## Принципы v1.0

1. **Не заменяем специалиста** — приложение ведёт по протоколу FOX, сложные случаи → человек FoodFox.  
2. **Не продаём приложение** — ценность = сопровождение после покупки теста.  
3. **Метрика успеха** — % клиентов, дошедших до 8-й недели и ретеста, а не скачивания.  
4. **Один backend** — Web и Android на общем API; контент (рецепты, KB) из админки FoodFox.
