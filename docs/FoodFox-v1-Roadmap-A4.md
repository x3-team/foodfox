# FoodFox v1.0 — план первой полноценной версии

**Модель:** приложение **бесплатно для клиента** после теста FOX. Партнёры-нутрициologи **рекомендуют тест** и получают **вознаграждение**.  
**Цель v1.0:** клиент прошёл программу · FoodFox управляет контентом · партнёры видят рефералы и выплаты.

---

## Три интерфейса (решение по платформам)

| Кому | Интерфейс | Платформа | Почему |
|------|-----------|-----------|--------|
| **Клиент** (после теста) | Мобильное приложение | **Flutter** (Android → iOS) | Ежедневное использование: план, рецепты, push, чат |
| **Команда FoodFox** | Админ-панель | **Web** (Next.js) | Контент, клиенты, партнёры, модерация — работа с ноутбука |
| **Партнёр-нутриciolog** | Партнёрский кабинет | **Web** (Next.js, отдельный раздел/поддомен) | Рефералы, статистика, выплаты, материалы — не нужно нативное приложение |

**Рекомендация:** партнёрам **не делать отдельное mobile app**. Достаточно **адаптивного web** (посмотреть статистику с телефона можно, но основной сценарий — desktop). Один backend, общая авторизация по ролям: `client` · `partner` · `admin`.

```
Клиент (Flutter)  ──┐
Админ (Web)       ──┼──→ API + PostgreSQL
Партнёр (Web)     ──┘
```

## Состав v1.0

### Клиентское приложение (Flutter)
Вход по коду/QR · результаты 286 · 4 фазы плана · меню/рецепты/покупки · push · дневник · обучение (KB) · чат · привязка к партнёру (опционально).

### Админ-панель (Web, FoodFox)
Рецепты и KB (CMS) · справочник продуктов FOX · клиенты и статус программы · модерация парсинга PDF · управление партнёрами (статусы, ставки) · аналитика · compliance-тексты.

### Партнёрский кабинет (Web, нутриciolog)
Регистрация / сертификация (после курса FOX) · персональная **реферальная ссылка/код** · список приведённых клиентов · начисления и история выплат · материалы для рекомендации теста · (v1.1) просмотр прогресса клиента с его согласия.

## Roadmap — 6 этапов

**1. После теста без трения**  
Код/QR · онбординг · release APK · парсинг PDF · **админ: базовый вход, роли, CRUD рецептов**.

**2. План и доверие**  
Plan Engine (4 фазы, ротация 🟡, молочный профиль) · «что можно сегодня» · **админ: просмотр клиента, правка плана**.

**3. Ежедневное сопровождение**  
Меню на день · покупки · push · прогресс · дневник · **админ: push-шаблоны, KB-статьи**.

**4. Партнёрская программа**  
**Web-кабинет партнёра:** реферальный код, учёт заказов, начисления · привязка клиента к партнёру при регистрации · **админ: ставки, выплаты, модерация партнёров**.

**5. Дойти до ретеста**  
Реинтродукция 🔴 · сравнение отчётов · повторный FOX · обучение · **партнёр: уведомление о ретесте «его» клиента**.

**6. Масштаб**  
API лаборатории · S3 для PDF · iOS · Store · **админ: дашборды, экспорт для бухгалтерии партнёрских выплат**.

---

## Принципы

1. **Mobile = только клиент.** Админ и партнёры — web.  
2. **Партнёр monetizes рекомендацию теста**, клиент app — бесплатное сопровождение.  
3. **Один API**, разграничение по ролям.  
4. **Успех:** клиенты дошли до ретеста + активные партнёры с прозрачными выплатами.
