# FoodFox — референсы дизайна

MVP v2 опирается на паттерны зрелых wellness-приложений:

| Референс | Что берём |
|----------|-----------|
| **Lifesum** | Мягкие карточки, зелёный акцент, чёткая типографика, summary-блок сверху |
| **Noom** | Дружелюбный тон, pill-переключатели, воздух между блоками |
| **Apple Health** | Статистика зон в compact cards, спокойный фон |
| **Headspace** | Скругления 16–20px, тени вместо жёстких border |

## Экран «Отчёт FOX» (v3)

Структура сверху вниз — от общей картины к деталям:

1. **Кольцевая диаграмма** зон + легенда с процентами (Apple Health)
2. **Вывод одной строкой** — «85% продуктов доступны без ограничений»
3. **CTA** — «Открыть план» / «Спросить бота»
4. **Главные триггеры** — топ-5 красных, нумерованный список с бейджами
5. **Сегмент-контрол зон** → поиск → список

Интенсивность полосок считается **относительно диапазона своей зоны**
(зелёная 0–10, жёлтая 10–20, красная 20–max), иначе все красные выглядят одинаково.

## Версионирование

| Файл | Назначение |
|------|------------|
| `VERSION` | Semver (`0.2.0`) |
| `apps/mobile/pubspec.yaml` | `0.2.0+N` — N = номер сборки |
| `scripts/bump-version.sh` | `build` / `patch` / `minor` / `major` |

Перед релизом: `bash scripts/bump-version.sh build` (или `patch`). CI для Android автоматически увеличивает номер сборки и кладёт APK в artifact с именем `foodfox-0.2.0 (N)-debug.apk`.

## Принципы v2

- **Текст никогда не обрезается** — `whitespace-normal`, ширина bubble по контенту (max 85%)
- **Без emoji в навигации** — SVG-иконки 24px
- **Карточки** — белый фон + `shadow-card`, без dashed border на primary CTA
- **Шрифт** — DM Sans (заголовки semibold, body regular, line-height 1.5)
- **Цвета** — тёплый фон `#F7F9F4`, primary `#256029`
