# FoodFox — референсы дизайна

MVP v2 опирается на паттерны зрелых wellness-приложений:

| Референс | Что берём |
|----------|-----------|
| **Lifesum** | Мягкие карточки, зелёный акцент, чёткая типографика, summary-блок сверху |
| **Noom** | Дружелюбный тон, pill-переключатели, воздух между блоками |
| **Apple Health** | Статистика зон в compact cards, спокойный фон |
| **Headspace** | Скругления 16–20px, тени вместо жёстких border |

## Принципы v2

- **Текст никогда не обрезается** — `whitespace-normal`, ширина bubble по контенту (max 85%)
- **Без emoji в навигации** — SVG-иконки 24px
- **Карточки** — белый фон + `shadow-card`, без dashed border на primary CTA
- **Шрифт** — DM Sans (заголовки semibold, body regular, line-height 1.5)
- **Цвета** — тёплый фон `#F7F9F4`, primary `#256029`
