## Сделано
- **hero-bg (S01)**: Real-ESRGAN x2plus → 2896×2172 (`hires/hero-bg-s01@2x.webp`). Hero на сайте — запечённый композит фрейма 1385:283, поэтому пересобран по рецепту Figma (градиент, волны с saturation −1 и linear burn, отражённая вырезка, тень снизу; `tools/bake_s01.py`, сверка рецепта с прежним файлом MAE 2,3/255) в `hero-desktop.webp` 1440, `@2x.webp` 2880, `.jpg`.
