## Что не удалось и почему
- **hero-bg, cta-bg, Австрия, p4.** В Figma нет исходников ≥ 2880 или ×2: залитые картинки сами по себе 736–1024 px. Нужен новый исходник (дизайнер, генерация или пересъёмка) либо векторный экспорт листа отчёта.
- **«Логотипы лабораторий» на /labs и /contacts.** Мутные `10243…10247.png` 256×256 из прошлого аудита оказались не логотипами, а тайлами карты OpenStreetMap (Leaflet). Чинится не исходником, а retina-тайлами: `L.tileLayer(url, { detectRetina: true })` или `{r}` в URL тайлов. Логотипы сетей в Figma векторные, на сайте уже SVG.
- **«Вес и отёчность».** В макете у четвёртой карточки симптомов нет фото, исходника не существует.
- **Поправка к IMG-DIFF.md.** Точный расчёт по `imageTransform` показывает, что у всех трёх CROP-слоёв симптомов одинаковая анизотропия: масштаб X/Y = 0,741. Значит, фото **сжаты по ширине на 26%** (вытянуты по вертикали ×1,35), а не растянуты ×1,18 вширь, как было написано раньше.
