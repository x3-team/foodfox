## 2. S13 стрелки на 1440 (`/`)

Ожидалось (REPORT §11, п. 4): две стрелки листают по карточке за 500 мс, лента останавливается под указателем и на стрелках.

Увидел:
- лента едет 60 px/с (`translate3d` на `.review-track`, по rAF); курсор на ленте → 0 px/с; курсор на стрелках → 0 px/с; увёл курсор → снова 60;
- кнопки 48×48 (`prev` x = 1269, `next` x = 1329, y = 100), переходы фона/рамки 150 мс ease-out;
- **«→»**: глайд измерен 466–469 мс (объявлено 500, минус шаг выборки), форма кривой по контрольным точкам 10/25/50/75 % → 28/56/86/98 % — это `1 − (1 − t)³` (расчёт 27/58/88/98). В конце карточка стоит ровно на левом крае ряда (x = 48, отступ ряда): после первого клика — карточка 2 (овальный отзыв), после второго — карточка 3;
- **три быстрых клика «→» через 90 мс**: цели складываются (`from = glide.to`), одно непрерывное движение ≈680 мс на три карточки (−347 → −1356), в конце карточка 5 на крае;
- **«←»**: глайд ≈480 мс, но лента остановилась на **−347 вместо −339**, ни одна карточка не на крае (8 px мимо).

Причина 8 px — шов двух копий ленты: копии стоят через 1695 px (5 × 339), а период обёртки берётся как `track.scrollWidth / 2 = 1687` (в `scrollWidth` нет зазора 16 px после последней карточки второй копии). Отдельно проверено на дрейфе: через ≈28 с (1687 / 60) лента перескакивает: карточка с x = 56,2 оказывается на x = 47,2 — рывок назад на 9 px между двумя кадрами. Так же любой клик по стрелке, когда ближайшая цель оказывается в «другой копии», встаёт на 8 px мимо.

Вердикт: **работает, но расходится на 8 px у шва** (прыжок каждые ≈28 с и промах «←» в примере). Раскадровки: `02-s13-next-1440.jpg`, `02-s13-prev-1440.jpg`, `02-s13-fast3-1440.jpg`.
