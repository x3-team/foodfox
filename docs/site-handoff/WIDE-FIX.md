## Пересборка S05
Скрипт `tools/sym-recrop.py <outdir>` (потом webp q90, @1x — Lanczos 324×520). Алгоритм: исходники `s7.png` (кожа), `s1.png` + альфа из `gut1.png` (ЖКТ), `s12.png` (самочувствие); imageTransform из узлов 1385:610/621/636; новый `a' = d·H_img·W/(H·W_img)`, `tx' = (a/2 + tx) − a'/2`; цвет — полином 3-й степени по RGB с членами по y, обученный на парах «старый варп → текущий экспорт».
