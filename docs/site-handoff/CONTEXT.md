## 10. Как мерить (инструменты и приёмы)

- **Playwright + headless Chromium.** Телефон — `{ width: 390, height: 844, hasTouch: true, isMobile: true }`; десктоп — 1440×900. Cookie-плашку убирать до загрузки:
  `addInitScript(() => localStorage.setItem("fox-cookie", JSON.stringify({ necessary: true, analytics: false, ads: false })))`.
- **Покадрово:** CDP `Page.startScreencast` или цикл скриншотов раз в 40–60 мс → контактный лист (Pillow) и смотреть глазами; параллельно на каждый `requestAnimationFrame` — `document.getAnimations()` (имя, duration, delay, easing) и computed styles (transform, opacity, filter, clip-path, height, scrollLeft).
- **Свайпы:** CDP `Input.dispatchTouchEvent` (touchStart → 8–12 touchMove → touchEnd). `synthesizeScrollGesture` в этой сборке не скроллит.
- **Скролл:** реальным колесом `page.mouse.wheel` малыми шагами, а не `scrollTo` — сцены по скроллу проверяются так, как листает человек. Учитывать `scroll-behavior: smooth`: `scrollTo` без `behavior: "instant"` ещё едет при замере.
- **Рывки:** 4× замедление CPU (`Emulation.setCPUThrottlingRate`), длинные кадры > 50 мс, `PerformanceObserver('layout-shift')`.
- **Контраст:** e2e-тест «text stays readable». Если меняется фон под текстом — делать фон отдельным слоем, а не `background-image`/градиентом на всю секцию: сэмплер считает такой фон фоном и под заголовком.
- **Сверка с Figma:** экспорт фрейма → кроп → попиксельное сравнение (средняя абсолютная ошибка; ≈1 — совпадение).
- Prod-сервер для замеров — свой порт; останавливать только свой процесс (по порту/cwd, не `pkill -f next`: можно убить чужие серверы и собственный shell).

## 11. Ограничения среды и общения

- **Не больше 5 картинок на одно сообщение** (в ответе заказчику и во вложениях). Контактные листы собирать в один JPEG ≤200 КБ.
- Скриншоты заказчика могут быть с монитора 27" при масштабе 150% — окно ≈1630 CSS px. Проверять и такие ширины (1600–1920, 2560).
- Облачный контейнер эфемерный: всё, что нужно сохранить, коммитить и пушить. Временные файлы — в scratchpad, не в репозиторий.
- GitHub — только через GitHub MCP (`gh` нет). PR не создавать без просьбы.
- Без явного поручения не трогать `apps/web`, `deploy/`, workflow, `main`; не отправлять формы на живом сайте.
