# Кабинет партнёра — демо-доступ

**Адрес:** https://foodfox.yuri.guru/partner  
**Шлюз сайта (nginx):** `demo` / `FoodFox2026!`

Вход такой же, как в приложении: номер телефона и код из СМС. Email и пароль больше не принимаются.

| | Телефон | Код | Роль | Куда попадает |
|---|---|---|---|---|
| Партнёр | `+7 999 000-11-22` | `2026` | `partner` | `/partner/home` |
| Клиент | `+7 925 111-11-11` | `1111` | `client` | в кабинет партнёра не входит |

Код `2026` действует только для номера партнёра. Клиентский код `1111` этот номер не открывает. Ответ `POST /api/auth/otp/request` не содержит `demoCode`, пока на сервере не включён `FOX_DEMO_MODE=1`. С флагом поле есть только у демо-номеров.

После входа партнёр видит демо-данные Марии Ковалёвой:

- сертификат `FOX-EDU-2026-0418`
- реферальный код `KOVALEVA-24`, ссылка `foodfox.ru/t/KOVALEVA-24`
- вознаграждение `2 400 ₽` за отчёт
- выплата: самозанятый, СБП •••• 4417

Страницы `/partner/home`, `/partner/reports`, `/partner/payouts`, `/partner/materials`, `/partner/certification` и `/partner/settings` открываются только с сессией роли `partner`. Заявка `/partner/apply` и статус `/partner/pending` остаются публичными.

В интерфейсе «285 антигенов»: в каталоге `packages/database/seeds/fox-catalog-ru.json` 285 уникальных имён, в шапке PDF отмечено 287. Числа 286 в этих данных нет.

Переопределение на сервере, если понадобится другой демо-номер: `FOX_PARTNER_DEMO_PHONE` и `FOX_PARTNER_DEMO_OTP`. По умолчанию используются значения из таблицы выше.
